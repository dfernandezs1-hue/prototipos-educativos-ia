Promedio móvil

Usa los últimos N períodos para pronosticar el siguiente. Recomendado cuando la serie es estable, sin tendencia ni estacionalidad fuertes.

Fórmula Ft+1 = ( Dt + Dt−1 + … + Dt−N+1 ) / N

Suavizado exponencial simple

Pondera cada observación con un peso decreciente exponencial. α controla la rapidez de adaptación: bajo suaviza, alto reacciona.

Fórmula Ft+1 = α · Dt + (1 − α) · Ft

Modelo de Holt — suavizado doble

Estima nivel y tendencia simultáneamente. Recomendado cuando la serie tiene tendencia y poca estacionalidad. La inicialización usa regresión lineal sobre los primeros valores.

Fórmulas Lt = α · Dt + (1 − α)(Lt−1 + Tt−1)
Tt = β · (Lt − Lt−1) + (1 − β) · Tt−1
Ft+n = Lt + n · Tt

Modelo de Winter — multiplicativo

Estima nivel, tendencia y factor estacional. Requiere al menos dos ciclos estacionales completos para inicializar correctamente.

Fórmulas (modelo multiplicativo) Lt = α · (Dt / St−p) + (1 − α)(Lt−1 + Tt−1)
Tt = β · (Lt − Lt−1) + (1 − β) · Tt−1
St = γ · (Dt / Lt) + (1 − γ) · St−p
Ft+n = (Lt + n · Tt) · St+n−p

Método estático con tendencia y estacionalidad

Procedimiento clásico de cinco pasos: desestacionalizar, ajustar tendencia lineal, estimar nivel y pendiente, recalcular factores estacionales y pronosticar.

Procedimiento 1. Desestacionalizar Dt con media móvil centrada de p períodos.
2. Ajustar regresión lineal: D̃t = L + T · t.
3. Factor estacional: St = Dt / D̃t, promediado por posición del ciclo.
4. Pronóstico: Ft = (L + T · t) · S(t mod p).
