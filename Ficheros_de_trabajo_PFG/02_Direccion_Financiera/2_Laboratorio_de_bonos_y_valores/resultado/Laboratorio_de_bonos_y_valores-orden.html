Conceptos fundamentales
→
Precio del bono
Valor actual de todos los flujos futuros (cupones + nominal) descontados a r.
→
Relación inversa precio–rentabilidad
Si r↑ → P↓. Si r↓ → P↑. Sin excepciones.
→
Clasificación por el par
r > c → bajo la par  ·  r = c → a la par  ·  r < c → sobre la par
→
Venta anticipada
P_venta = P(r_mercado, años restantes). Beneficio = cupones cobrados + P_venta − P_compra.
→
TAE vs. rentabilidad simple
La TAE es la TIR: tasa que iguala el precio de compra con los flujos futuros descontados.
Fórmula
P = C · [1-(1+r)^(-n)] / r + N · (1+r)^(-n) C = N × c% cupón anual en euros r = rentabilidad exigida (decimal) n = años hasta vencimiento N = nominal Caso especial: si c = r → P = N (a la par, siempre)
Razonamientos que debes dominar
1. El precio es el único valor que garantiza al inversor exactamente la rentabilidad r que exige.
2. El cupón es fijo (lo fija el emisor). La r varía con el mercado. Su diferencia determina la prima o descuento.
3. Al vencimiento siempre se cobra el nominal. El precio converge a N conforme se acerca el vencimiento.
4. Mayor duración → mayor sensibilidad al cambio de r. Un bono a 20 años cambia más de precio que uno a 2 años ante la misma variación de r.
5. La TAE no es beneficio/inversión/años. Hay que resolver la ecuación implícita del valor actual.
Pregunta de comprensión

Bono con cupón 4%, nominal 1.000 €, rentabilidad exigida 7%.

¿El precio es mayor, igual o menor que 1.000 €? ¿Por qué? ¿Qué ocurre si r baja al 4%?
